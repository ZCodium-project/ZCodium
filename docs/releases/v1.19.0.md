# ZCodium v1.19.0

本版在 v1.18.0 基础上完成 4 次上游审计同步与 6 项功能、修复；遥测保持移除，未恢复官方账号、公网 relay 或自动上传。

## 本次更新

### 会话与编辑

- **历史用户消息可编辑并重发**（#136 / #135）：把行内编辑从“仅最后一条”扩展到当前分支内所有带持久消息 ID 的真实用户输入。发送后保留目标之前的对话，替换目标及其之后的轮次；历史编辑保留工作区文件，最新一轮仍提供“连文件一起重置”。运行中提交会先停止旧工作再重跑，压缩锁、goal 重放、队列与附件语义保持原状。

### 模型与供应商

- **Standard Compute 预设**（#126 / #125）：OpenAI Chat Completions，`https://api.stdcmpt.com/v1`，内置 `StandardCompute`、`deepseek/deepseek-v4.1-flash`、`z-ai/glm-5.3`。按官方试用额度取 500,000 本地输入+输出总预算与 32,768 单请求输出上限，只作用于该站点；补齐 API Key 管理入口。
- **MartLLM 预设**（#128 / #127）：原 UberLLM，现行为 `https://api.martllm.com/v1`，内置 DeepSeek V4.1 Flash 与 GLM-5.3，按站点映射 `max_tokens` 与 `reasoning_effort`。旧域名由供应商兼容，未发布过旧预设，因此不提供迁移。
- 两家预设使用现有通用图标，不打包未获分发授权的商标。

### 上游同步（审计后仅同步安全子集）

- **v3.18.0**（#130）：Agent 崩溃诊断共享工具与统一 stderr 脱敏；Git 输出流回调（供受管 worktree 进度使用）；插件技能扫描的单技能边界；退出登录后的账号投影修复；Source Server 更新中错误码；Windows 运行时宿主模块（本地进程托管，未接入打包，不含新增上报）。
- **v3.18.1**（#132）：CLI 内存诊断与反馈日志归档；思考块流式容器与排队摘要渲染修复；交互来源徽标换行；手机远控返回；侧栏最小宽度、侧板上限与项目菜单拖拽区修复。本地另修：诊断写入与三类归档共用当前数据根，旧目录不再被混入；手机聊天历史只有从列表进入才拥有列表前项，直达聊天就地回列表且不额外增殖历史。
- **v3.18.2**（#134）：插件能力图与后台 Bash 文档措辞同步，仅文档改动。
- **v4.0.0 独立 UI**（#138 / #139 / #140）：中文裸链接不再吞掉 Markdown 强调收尾，且不改写显式链接、引用定义、行内代码与代码块原文；工作流侧栏补全框不再把测量尺寸写回自身、不再改变滚动范围。依赖 v4 会话运行时、插件发现、预装工具的部分未同步；无调用方的 Progress indeterminate 暂未纳入。

### 修复与质量

- **后台窗口提示不再丢失**（#120）：全局提示的投递改为同步缓冲、挂载即排空，进入动画交给 CSS；显示态不再等待动画帧。窗口被遮挡或最小化时，“保存成功”“连接失败”等提示仍会出现并按时关闭。
- **全仓文本按 LF 归一并保持字节敏感面**（#122）：`.gitattributes` 增加 catch-all，Windows 检出不再产生行尾伪差异；`.bat`、许可台账、二进制与 vendored 资产保持原字节。
- **Windows 打包解压修复**（#142）：GitHub runner 镜像升级后 `Expand-Archive -Force` 在 Windows PowerShell 中失败，改为直接调用 .NET `ZipFile::ExtractToDirectory`，SHA-256 校验与二进制定位不变。
- 随 UI 改动刷新第三方许可台账，并在 Linux 复生成比对一致。

## 发布验证与边界

- **构建**：macOS arm64 / x64、Windows x64、Linux x64 / arm64 桌面，以及 CLI、远端资源、校验和与更新清单全部成功。
- **macOS arm64 真实安装包**：内置版本与提交一致；设置中可见 `Standard Compute` 与 `MartLLM` 预设；自定义供应商 → 模型检测 → 保存启用 → 流式回复与多轮对话正常；中文粗体裸链接、显式链接目标、行内代码、代码块原文均保持正确；运行中禁用 `requestAnimationFrame` 后提示仍显示并自动关闭；日志导出正常落盘在隔离数据目录。
- **未覆盖**：Windows / Linux GUI 实机、真实手机远控与公网 relay、付费供应商实网多轮工具调用、完整全量单测。相关改动的定向测试与浏览器回归见各 PR。
- macOS 包仍未签名，需下载对应架构 DMG 后手动替换安装；Windows 可能出现 SmartScreen 提示；Linux AppImage 需赋予执行权限。
- **已知遗留**：远程控制“刷新二维码”仍报 `No handler registered for 'zcode:reset-web-remote-control-pairing'`（preload 已 invoke、main 未注册，属既有缺口，单独跟踪）；#106 / #107 等既有 issue 继续独立处理。

## English summary

v1.19.0 adds inline editing for historical user messages (same-session branch cut, workspace files preserved), the Standard Compute and MartLLM (formerly UberLLM) API-key presets, and four audited upstream syncs: v3.18.0 crash diagnostics and stderr redaction, v3.18.1 CLI memory diagnostics, UI and mobile remote fixes, v3.18.2 documentation wording, and the standalone v4.0.0 UI fixes for CJK bare links and workflow fill frames. Fixes include toasts that no longer depend on animation frames, repository-wide LF normalization, and Windows packaging after a runner image regression. Telemetry remains removed. All five desktop targets build; a real macOS arm64 package was verified for presets, streaming chat, Markdown rendering, toasts without animation frames, and log export. Windows/Linux GUI, real-device remote control, and paid-provider live inference were not tested. Unsigned macOS builds still require manual installation.
