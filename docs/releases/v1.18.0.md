# ZCodium v1.18.0

本版同步上游 v3.17.1 / v3.17.2，并修复 10-10 再基线覆盖的两处本地改动；遥测保持移除。

## 本次更新

### 上游同步：v3.17.1（#103）

- Source Server 远端生命周期与诊断：设备级 stop/restart/running-tasks、生命周期互斥、信号退出码、Docker/SSH/WSL 探测诊断；glibc/musl 不兼容改为警告继续，不再阻止已有服务的连接与安装。
- 本地文件菜单：按系统关联枚举可打开文件的应用，支持「打开方式 / 另存为」；不维护应用白名单、不拼接 shell，打开前重新校验目标与应用身份。
- CLI 运行时/更新：组件缓存、锁身份校验（PID 复用防护）、不可变 release 的损坏副本替换修复。

### 上游同步：v3.17.2（#113）

- 内置浏览器本地 HTML 预览：新增 `zcode-html` 协议与 main 导航准入（HMAC 签名、realpath 包含校验、目录与扩展名限制），浏览器分区内封闭原始 `file:` 协议。
- MCP 失败诊断与 stderr 脱敏：设置页展示处理建议与错误详情，敏感值脱敏。
- 子智能体插件权限收紧；打包平台依赖裁剪（node-pty 平台包与 JS 同版本配对）。
- 遥测保持移除（审计结论：未发现新增遥测）。

### 模型与界面

- 新增 cheapaimodel API Key 预设（#116）：DeepSeek V4.1 Flash / GLM-5.3，第三方 OpenAI 兼容网关，与 Cheaper Inference 同一模式；不是智谱官方入口。
- 恢复侧栏版本号显示（#37，10-10 再基线覆盖）。
- 移除智谱套餐预设入口（#16，10-10 再基线覆盖）：Z.ai / BigModel 仍作为普通 api-key 模板；不再展示「连接 BigModel / Start Plan」套餐连接卡。
- release CI 的 CLI 构建固定 `ZCODE_ENV=production`，避免 CLI 发行包漏掉本地预设（OrcaRouter / Cheaper Inference / cheapaimodel）。

### 质量

- 修复上游行为变化对应的测试适配（锁身份、损坏副本替换、WSL 身份探测、node-pty 平台包、本地预览导航、沙箱 scheme 注入）；合并后 11 个相关测试文件共 231 tests 全绿；typecheck / lint 0 error。

## 发布验证与边界

- 验证范围：根类型检查、Lint、相关单测（231）、macOS Apple Silicon production 包构建与启动（主界面、设置、模型设置、本地 HTML 预览协议注册）。
- 未执行全量单测；未在 Windows/Linux GUI、真实手机/SSH、付费供应商实网推理验证。
- macOS 包未签名，需手动解除 Gatekeeper；Windows 可能出现 SmartScreen 提示；Linux AppImage 需赋予执行权限。
- 已知遗留：上游同步带入的 Start Plan 推荐/营销文案仍可能存在（非本次范围）；#106 / #107 等既有 issue 继续独立追踪。

## 下载与安装

macOS 包仍未签名，需下载对应架构的 DMG，退出 ZCodium 后拖入「应用程序」替换旧版，无需删除用户数据。更新检查与手动下载入口不代表原生自动安装能力；Windows/Linux 原更新行为保持。

| 平台                | 安装包                                 |
| ------------------- | -------------------------------------- |
| macOS Apple Silicon | `ZCodium-1.18.0-mac-arm64.dmg`         |
| macOS Intel         | `ZCodium-1.18.0-mac-x64.dmg`           |
| Windows x64         | `ZCodium-1.18.0-win-x64.exe`           |
| Linux x64           | `ZCodium-1.18.0-linux-x86_64.AppImage` |
| Linux arm64         | `ZCodium-1.18.0-linux-arm64.AppImage`  |
| CLI（Node.js 24）   | `zcodium-1.18.0.tar.gz`                |

请核对发行来源及 `sha256.txt`。Gatekeeper 拦截时参照 DMG 的中英文解除拦截说明；Windows 可能出现 SmartScreen 提示；Linux 需赋予 AppImage 执行权限。

## English summary

Syncs upstream v3.17.1 / v3.17.2: Source Server remote lifecycle and diagnostics, the local file menu, embedded-browser local HTML preview (`zcode-html` with main-process admission), MCP failure diagnostics with stderr redaction, subagent plugin permission tightening, and platform-specific packaging cleanup. Telemetry remains removed. Adds the cheapaimodel API-key preset, restores the sidebar version label, and removes the restored Zhipu plan connection cards; Z.ai / BigModel remain ordinary API-key templates. The release CLI build now pins `ZCODE_ENV=production` so local presets are not dropped. Validation covers typecheck, lint, 231 affected tests, and a local production package launch on macOS Apple Silicon; full unit tests and cross-platform GUI were not run. Unsigned macOS builds still require manual installation.
