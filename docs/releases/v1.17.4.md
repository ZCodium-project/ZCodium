# ZCodium v1.17.4

本版接续未公开的 v1.17.3 草稿候选，保留其修复并重新构建验收；不把草稿当作此前已发布版本。

## 本次更新

### 归档管理与项目文件树（#99 / #104 / #109）

- 恢复「设置 → 数据与统计 → 归档管理」，支持查看、搜索、取消归档和确认删除。
- 修正冷启动历史管理对可用模型配置的错误依赖；历史删除仍通过既有 CLI 命令和会话所有者执行，不由 UI 直接写数据库。
- 项目文件树为顶部标题栏保留空间，避免返回按钮被浮层覆盖；鼠标和键盘返回保持项目展开状态。
- 不修改自动归档策略、会话归属或桌面/手机流式恢复语义。

### 模型检测与供应商预设（#97 / #100，PR #98 / #101）

- 补齐模型探测执行器装配；检测读取当前连接草稿，不启动模型推理，不通过检测动作保存配置或改写注册表。连接字段原有自动保存不变。
- 对非法请求头、网络异常和 URL 回显中的 API Key、认证头及其他敏感信息脱敏。
- 新增 Cheaper Inference API Key 预设，包含 `gpt-5.4-mini`、`claude-sonnet-5` 及相应参数；品牌资源保留可追溯来源和许可说明，不默认发起请求。

### 质量与构建门禁（#93 / #95 / #108，PR #94 / #96）

- pre-push 补根类型检查；它不覆盖完整 Desktop Main，也不能捕获所有语义回归。
- 修复浏览器入口意外引入 Node 模块的问题，增加 AST/模块解析和独立负夹具守卫。
- 迁移退役的 macOS arm64 runner，保持 Intel 与 Apple Silicon 原生构建分离。

感谢原 PR 贡献者；本版保留其提交，并追加必要的安全修正及回归。

## 发布验证与边界

采用「完整工件构建为 draft → 校验并实测同批工件 → 合并候选 → 公开为 Latest」流程。验证范围为根类型、Lint、增量架构、schema、Web 构建及受影响专项，以及真实包的模型探测、归档管理、文件树返回和 macOS 手动更新；无模型历史管理需单独验收，不能以已配置模型的正向结果代替。

没有执行全量单测；不宣称 Windows/Linux GUI、真实手机/SSH、付费供应商实网推理通过。新增导航 WDIO 保持 pending，fixture/类型检查不等于真实 E2E。

上游同步 PR #103 未纳入，仍有远端更新时序及回归阻塞；不宣称新增低 glibc 支持、设备生命周期、文件应用菜单或图片编辑。另有既有问题 #106（从源码 cwd 启动时 CLI 选择边界）和 #107（macOS 设置页无效自动安装开关）继续独立追踪，不冒称已修复。

## 下载与安装

macOS 包仍未签名，需下载对应架构的 DMG，退出 ZCodium 后拖入「应用程序」替换旧版，无需删除用户数据。更新检查与手动下载入口不代表原生自动安装能力；Windows/Linux 原更新行为保持。

| 平台                | 安装包                                 |
| ------------------- | -------------------------------------- |
| macOS Apple Silicon | `ZCodium-1.17.4-mac-arm64.dmg`         |
| macOS Intel         | `ZCodium-1.17.4-mac-x64.dmg`           |
| Windows x64         | `ZCodium-1.17.4-win-x64.exe`           |
| Linux x64           | `ZCodium-1.17.4-linux-x86_64.AppImage` |
| Linux arm64         | `ZCodium-1.17.4-linux-arm64.AppImage`  |
| CLI（Node.js 24）   | `zcodium-1.17.4.tar.gz`                |

请核对发行来源及 `sha256.txt`。Gatekeeper 拦截时参照 DMG 的中英文解除拦截说明；Windows 可能出现 SmartScreen 提示；Linux 需赋予 AppImage 执行权限。

## English summary

Restores archive management and file-tree navigation, removes the model-configuration dependency from history management, repairs model discovery with credential-safe errors, adds the Cheaper Inference preset, and strengthens quality/build gates. The v1.17.3 draft was not published. Unsigned macOS builds still require manual installation. PR #103 and existing issues #106/#107 are not claimed resolved. Validation scope and platform limitations are stated above.
