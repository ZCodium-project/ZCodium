# ZCodium v1.17.3

## 本次更新

### 1. 恢复归档管理与文件树返回（#99 / #104）

- 恢复「设置 → 数据与统计 → 归档管理」入口，可查看、搜索已归档会话，并使用原有取消归档和确认删除操作。
- 项目文件树为顶部标题栏预留空间，避免返回按钮被顶部浮层覆盖；返回项目列表不重置项目展开状态。
- 不修改自动归档策略、会话存储归属或远端协议。

### 2. 修复可用模型检测（#97，PR #98）

- 修复设置页检测模型时提示 Environment 未装配探测能力的问题，将现有探测执行器接入桌面和服务端运行时。
- 检测读取当前连接草稿，不启动 Agent，也不通过检测操作保存配置或改写模型注册表；设置字段原有的自动保存行为不变。
- 修正非法请求头和网络错误可能回显凭据的问题，返回错误前对 API Key、认证头及 URL 中的敏感信息脱敏。

### 3. 新增 Cheaper Inference 预设（#100，PR #101）

- 新增 API Key 供应商预设，包含 `gpt-5.4-mini`、`claude-sonnet-5` 模型及对应参数。
- 使用可追溯来源的品牌资源并保留许可说明；不会因预设存在而默认发送网络请求。

### 4. 补齐质量门禁（#93 / #95，PR #94 / #96）

- pre-push 增加根类型检查。该检查不覆盖完整 Desktop Main，也不能发现所有类型正确的语义回归。
- 修正浏览器入口意外引入 Node 模块的问题，并以 AST、模块解析和独立负夹具检查 browser-safe 闭包。

感谢上述 PR 的贡献者；本版保留原贡献提交，并追加安全修正和回归验证。

## 发布验证与边界

本版采用「完整工件构建为 draft → 校验并实测同批工件 → 公开为 Latest」流程，不以构建成功代替流程验收。专项验证范围包括模型检测成功/认证失败/连接草稿变化、预设显示、归档取消与确认删除、文件树鼠标及键盘返回，以及 macOS 手动更新提示。模型接口使用本地受控服务，不冒称付费供应商实网调用通过。

根类型检查、Lint、增量架构检查、数据库兼容检查、Web 构建及相关定向回归独立执行；没有执行全量单测。不宣称 Windows/Linux GUI、真实手机或 SSH 全链路验收通过。新增导航 WDIO 用例仍为 pending，不以 fixture/类型检查代替真实执行。

**本版不包含上游同步 PR #103。** 其远端更新时序和新增回归仍需修正；不宣称新增低 glibc 支持、设备生命周期控制、文件应用菜单或图片编辑功能。

待发布决策的已知限制：冷启动且未配置可用模型时，删除历史归档会话仍被模型就绪门禁阻止（[#109](https://github.com/ZCodium-project/ZCodium/issues/109)）。配置本地受控模型后的归档操作验收通过，不代表此无模型场景已经修复；候选保持 draft，不能据此宣称全部场景无问题。

## 下载与安装

macOS 安装包仍未签名，继续采用明确的手动安装流程：下载对应架构的 DMG，退出 ZCodium 后拖入「应用程序」替换旧应用，无需删除用户数据。检查新版不等于支持原生自动安装；Windows/Linux 更新行为保持不变。

| 平台                | 安装包                                 |
| ------------------- | -------------------------------------- |
| macOS Apple Silicon | `ZCodium-1.17.3-mac-arm64.dmg`         |
| macOS Intel         | `ZCodium-1.17.3-mac-x64.dmg`           |
| Windows x64         | `ZCodium-1.17.3-win-x64.exe`           |
| Linux x64           | `ZCodium-1.17.3-linux-x86_64.AppImage` |
| Linux arm64         | `ZCodium-1.17.3-linux-arm64.AppImage`  |
| CLI（Node.js 24）   | `zcodium-1.17.3.tar.gz`                |

请核对发行来源和 `sha256.txt`。macOS 首次打开若被 Gatekeeper 拦截，参照 DMG 内的 `解除拦截.txt` / `Unblock.txt`；Windows 可能显示 SmartScreen 提示；Linux 需给 AppImage 执行权限。

## English summary

Restores archive management and file-tree navigation. Repairs model discovery runtime wiring and redacts credentials from discovery errors, adds the Cheaper Inference preset, and strengthens pre-push type checks and browser-safe entry guards. Releases are tested as drafts before the same assets are made public. Unsigned macOS builds still require manual installation. PR #103 is excluded due to unresolved remote-update and regression issues. No full-suite, Windows/Linux GUI, real mobile/SSH or paid-provider live validation is claimed.
