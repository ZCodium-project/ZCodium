# SSH 远端运行时：自动下载、内网镜像与离线导入

从 **ZCodium 1.16.3** 起，安装包默认使用本仓 GitHub Release，不再尝试官方 ZCode CDN 的同号资源。运行时资源与应用版本必须完全一致。

## 常规联网使用

添加 SSH 时保持「运行时资源 → 自动下载／自定义镜像」。应用下载、校验对应平台运行时，再经 SSH 上传。目标服务器不需要访问公网。已有兼容运行时直接连接。

企业镜像可填写**包含版本的完整 HTTP(S) 目录地址**，其下必须有 `source-server-release.json` 和对应 `zcode-server-<平台>.tar.gz`。地址不得带用户名、密码、查询参数或 fragment。镜像失败不回退其它公网源。

应用仍兼容运行时环境变量 `ZCODIUM_REMOTE_ASSET_CDN_BASE_URL`（旧名 `ZCODE_REMOTE_ASSET_CDN_BASE_URL`）。Finder/开始菜单启动不一定继承终端环境，建议使用向导中的可视化配置。

## 完全离线使用

以 1.16.3 连接 Linux x64 为例：

1. 在可联网机器上打开 <https://github.com/ZCodium-project/ZCodium/releases/tag/v1.16.3>。
2. 下载 `source-server-release.json` 与 `zcode-server-linux-x64.tar.gz`，保持原文件名并放在同一个目录。Linux ARM64 换为 `zcode-server-linux-arm64.tar.gz`；macOS 对应 darwin 文件。
3. 将目录复制到运行桌面应用的内网机器，不必提前传到服务器。
4. 在添加 SSH 的连接设置中，点击「导入离线运行时」并选择该目录。
5. 确认出现「已校验并导入」及正确的平台/版本，界面会自动改成「仅离线（不访问公网）」，再继续连接并确认安装。

仅离线模式不会请求资源清单，不会让远端执行公网下载。即使线路原来选择「远端直接下载」，也由本机上传已校验包。只需导入需要的平台；应用升级后应重新导入新版本运行时。

## 错误处理与信任边界

- **缺包／平台不匹配**：下载描述文件列出的正确平台包，不要重命名其它平台的包。
- **版本不匹配**：不能将上游 3.x、旧 1.x 或其他构建的包冒充当前版本。
- **校验失败**：重新获取原始文件；不能编辑 descriptor 来绕过检查。SHA-256 只证明完整性，请只从可信 Release 或公司镜像获取文件。
- **导入失败**：旧的可用导入不会被半包覆盖；原目录中的文件也不会被修改。
- **离线模式缺少当前资源**：立即提示缺包，不会先等待外网超时。需要联网时，显式切回自动模式。

该设置是桌面控制端全局偏好，不改变 workspace 身份、会话路由或安装升级的运行中任务保护。手机 Web 不提供本机目录导入入口。

「仅离线」限定运行时资源获取，不是整个应用的断网开关；模型 API、应用更新等仍按各自的配置工作。
