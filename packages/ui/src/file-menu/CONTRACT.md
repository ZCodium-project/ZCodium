# 文件菜单

文件菜单展示当前文件的系统关联应用并导出原始副本。目录沿用调用方原来的编辑器菜单。

- 系统应用只查询和打开本机真实文件，远程工作区不把路径交给本机应用。
- 应用列表属于当前目标和当次查询；切换路径或卸载后旧结果失效。
- 保存由所属 workspace Host 的 `stat/readFileRange` 读取，最多 50 MiB。读取前后核对尺寸和修改时间，不做文本解码。
- `saveFile` 是唯一保存端口。先完成读取再打开保存对话框，允许用户选择源路径；取消是正常结果。
- UI 只维护查询和按钮忙碌状态，不持有 task/session/stream 状态。
